# **Agenda de contactos**
Es una implementación de un TAD para administar contactos ordenados alfabéticamnete por nombre.
---
* Permite agregar, eliminar y consultar contactos, además de obtener sus nombres y teléfonos.
* La búsqueda de contactos se realiza mediante búsqueda binaria.
* los archivos `agenda.py`, `test_agenda.py` y `medicion.py` deben encontarse en la misma carpeta.
* *Para ejecutar las pruebas se utiliza el comando:
``python -m pytest -q``
* La implementación evita el uso de `bisect`, `in`, `.index()`, `sorted()` y `.sort()` para las operaciones de la Agenda.
